# Virtual Auto Market — панель управления

Админ-панель на Next.js (JSX) + SCSS для виртуального авто-маркета.
Подключается к готовому API (вход, категории, автомобили, статистика).

## Технологии

- Next.js 14 (Pages Router)
- React 18
- SCSS Modules (тёмная digital-glass тема)

## Структура

```
components/   Layout, Modal — переиспользуемые UI-блоки
context/      AuthContext — токен, пользователь, login/logout
lib/api.js    обёртка над fetch для запросов к бэкенду
pages/        login, dashboard, categories, products
styles/       SCSS-модули + переменные темы
```

## Разделы панели

- **Главная** — общая статистика (авто, категории, заказы, клиенты, стоимость склада)
- **Автомобили** — список с фильтрами, добавление/редактирование, статус, удаление
- **Категории** — список, добавление/редактирование, статус, удаление
- **Заказы** — список с фильтром по статусу, смена статуса, детальная страница заказа
- **Клиенты** — список пользователей, блокировка/разблокировка
- **Отзывы** — модерация отзывов (одобрить/скрыть/удалить)
- **Баннеры и акции** — управление слайдером на витрине (создание/редактирование/статус/удаление)
- **Уведомления** — история рассылок + отправка нового push-уведомления
- **Точки выдачи** — список, добавление/редактирование, удаление

> Разделы «Заказы», «Клиенты», «Отзывы», «Баннеры и акции», «Уведомления» обращаются к эндпоинтам
> `/orders`, `/users`, `/reviews`, `/banners`, `/notifications` через тот же `lib/api.js`.
> Если на бэкенде эти маршруты называются иначе — поправьте пути в соответствующих `pages/*.jsx`,
> сама структура страниц (таблица + фильтры + модалка) уже готова.

## Запуск

1. Установить зависимости:
   ```
   npm install
   ```
2. Скопировать `.env.example` в `.env.local` и указать адрес бэкенда:
   ```
   NEXT_PUBLIC_API_URL=https://backend.magnateshop.uz
   ```
3. Запустить:
   ```
   npm run dev
   ```
4. Открыть http://localhost:3000 — данные для входа по умолчанию:
   `admin / admin123`

## Заметки

- Все запросы идут через `lib/api.js` (`api.get/post/patch/put/del`).
- Токен хранится в `localStorage` под ключом `as_token`.
